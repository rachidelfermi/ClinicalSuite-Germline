# Conda environment provenance

ClinicalSuite migrated its runtime packaging from Apptainer to Conda on
2026-08-03 because production HPC policy disables user namespaces and setuid
container execution. The scientific workflow did not change.

## Reproducibility records

Each runtime has three evidence layers:

1. a version-pinned input specification;
2. `NAME.lock`, generated by `mamba list --explicit`, which fixes platform,
   channel, version, build, and package artifact; and
3. resolved `NAME.yml`, exported only after executable and integrity validation.

`conda-pack` runs after all environments pass. SHA-256 values for deployment
archives are recorded in `archive_checksums.sha256`; the per-tool evidence is in
`environment_validation_report.txt`.

## Dependency isolation decisions

QC, alignment, general variant tooling, DeepVariant, Octopus, annotation, and
reporting use separate prefixes. DeepVariant is pinned to the CPU TensorFlow
build. Caller-specific prefixes are necessary because current GATK,
DeepVariant, and Octopus packages impose incompatible Java/HTSlib constraints.
This isolation does not affect files or command contracts exposed to modules.

The upstream Bioconda 1.10.0 recipe is dependency-only and omits its executable
ZIP payload. ClinicalSuite reuses the locally validated official CPU payload at
digest `sha256:962e5a83b1d76aae6990625d47102785f791603f2138aa1fa9aa4fb6a2eecbe6`.
The official ZIPs remain byte-identical; a local Conda package changes only
launcher paths for relocation, and Mamba performs the install. No model is
extracted or packaged.

## External resources

No environment contains GRCh38, BWA-MEM2 indexes, DeepVariant models, VEP
caches/plugins, ClinVar, dbSNP, gnomAD, LOFTEE, REVEL, SpliceAI, dbNSFP, or ACMG
resources. Their checksums and compatibility are evaluated independently.

## Build policy

Installations use Mamba only. `conda install` and `conda create` are prohibited.
Existing complete prefixes are repaired in place with `mamba install`; they are
not deleted or recreated. Prefixes are activated by the launcher through an
isolated environment and never require user shell activation.
